# Cookie Checkpoint

Cookie Checkpoint is a small, open-source on-chain streak app for Cookie Chain. It turns a daily check-in into a verifiable transaction that can be opened in Cookiescan.

## What it does

- Detects and connects to Nightly through the standard Solana wallet interface.
- Switches Nightly to Cookie Chain when the wallet exposes network switching.
- Reads the connected wallet's COOK balance, current slot, and recent signatures from the Cookie Chain RPC.
- Creates a signed check-in transaction using a zero-value self-transfer and a readable Memo Program payload.
- Waits for confirmation and links each completed checkpoint to Cookiescan.
- Keeps the local streak trail in browser storage; the signed checkpoint itself is public on-chain activity.

## Run locally

Requirements:

- Node.js 22.13 or newer
- Nightly browser extension for wallet testing
- A Cookie Chain wallet with enough COOK to pay a transaction fee

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in a browser with Nightly installed.

## Cookie Chain configuration

The app uses the official Cookie Chain RPC endpoint:

```text
https://rpc.cookiescan.io
```

The app does not ask for, store, or transmit seed phrases or private keys. Nightly performs wallet approval locally.
